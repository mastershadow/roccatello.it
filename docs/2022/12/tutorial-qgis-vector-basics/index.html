QGIS vector data loading and styling basics

How to load vector data in QGIS and how to use the main data browsing tools. Also basic styling.

2022-12-18 1 min di lettura

In this episode I’ll show you how to load vector data in QGIS and how to use the main data browsing tools. Also I will show you how to do some basic styling for vector data (points, lines, polygons).

What is QGIS?

QGIS is a professional GIS application that is built on top of and proud to be itself Free and Open Source Software (FOSS).

Eduard Roccatello — co-fondatore e CTO di 3DGIS.
